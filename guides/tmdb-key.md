# Get a TMDB API key

**Used for:** searching movies, TV, animation and documentaries.
**Site:** [themoviedb.org](https://www.themoviedb.org)
**Last checked:** _not yet written up_

A personal key is free and is approved on the spot.

## 1. Create an account and open the API settings

Create a free account, sign in, then open **Settings → API**.

<!-- TODO screenshot: images/tmdb-1-settings-api.png — the API page in TMDB's settings -->

## 2. Request a Developer key

Choose to request a **Developer** key (personal use is approved straight away) and fill in the form:

- **App name:** anything
- **App URL:** `http://example.com`
- **Summary:** anything, for example "Personal key for Serialized media checklister"

<!-- TODO screenshot: images/tmdb-2-request-key.png — the form, filled in -->

## 3. Copy the key into Listulator

Copy the **API Key** (not the long "API Read Access Token"), open **Settings → API keys** in Listulator, paste it into the TMDB row and press **Test**. The pill should say **Working**.
